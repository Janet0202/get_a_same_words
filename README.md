# 同词相逢 · 默契接力路

手机优先的多人词语联想网站。Python 3.12 标准库服务端与原生 HTML/CSS/JavaScript，无需安装第三方依赖。

## 启动

```sh
cd /workspace/get_a_same_words
python3 server.py
```

默认监听 8000 端口，可用 `PORT` 覆盖。浏览器访问部署主机的相应端口。创建或加入房间时自动生成随机昵称，同房间内不会重名，无需填写。创建房间后，通过房间码或邀请链接加入；同一浏览器测试多个玩家时使用不同标签页（每页身份保存在 sessionStorage）。至少两人，最多八人。

## 规则

第一轮自由输入词语，全部提交后揭晓。词语不一致则共同前进 100 米，所有人点击准备后进入下一轮，参考上一轮词语继续联想。所有人去除首尾空白后的词语完全一致时结束。等待时可以点点迈步和发送表情。语音交流使用线下或外部通话，目前未集成语音。

## Render 部署

仓库内的 `render.yaml` 声明免费 Python Web Service。在 Render 登录并连接此 GitHub 仓库，选择 New → Blueprint，使用此文件创建服务。检查套餐为 Free 后部署。若免费资源额度已用完，不要改用付费套餐；先检查账户配额。

部署成功后打开 Render 提供的 HTTPS 地址，用两个独立浏览器创建和加入房间，完成一轮不同词及一轮相同词测试，再分享邀请链接。此流程需要 Render 账户授权；仅上传 GitHub 不代表网站上线。免费实例的休眠、重启或重新部署会丢失所有内存房间，请勿启用多个实例。

## 开发边界

此版本是可联机开发原型：房间保存在内存，服务重启后丢失；玩家中途离开可能使当前轮等待，需要另开房间。不含账户、持久存储、断线玩家管理和生产级限流。公开运营前应补充这些能力并使用 HTTPS 反向代理。环境的代理连接与 GitHub 推送权限由平台管理，不需要在聊天中提供令牌。
